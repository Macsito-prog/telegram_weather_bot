## Telegram Weather Bot

This was created in order to get the weather directly on telegram, app which I've been using a lot lately. 

## How does it work:
1.- First start the bot with the /start command.  
2.- using /ciudad [name] stores the name of your city or location you want to check the weather on.  
3.- finally, using the command /clima returns the temperature of the previously saved city in °C.
